Chrome extension / Case study

Local Lead Intelligence

A prospecting tool that turns raw Google Maps discovery into a verification, enrichment and scoring workflow.

Chrome extensionData workflowScoringEvidence-backed UX
01 / PROBLEM

What needed solving

A raw list of local businesses is not enough. Prospecting becomes useful only when details are verified and the user can understand which opportunities deserve attention first.

02 / BUILD

What I built

I built a Discover → Verify → Enrich → Score pipeline with website-opportunity signals, business signals, issue detection and source evidence inside the extension.

03 / VALUE

What this demonstrates

It demonstrates browser tooling, data workflows and decision-oriented UX — not just scraping or exporting a list.
